# Carpeta de modelos de idioma (offline)

Coloca aquí archivos `.argosmodel` (paquetes de Argos Translate) y en la interfaz
pulsa **Idiomas… → Sincronizar carpeta models/** para instalarlos.

## De dónde salen los `.argosmodel`

- Índice oficial: https://www.argosopentech.com/argospm/index/
  (o desde la app: **Idiomas… → Cargar índice online**, requiere internet una vez)
- Una vez instalado un par, la traducción funciona 100% sin internet.

## Pares recomendados para empezar

| Archivo                | Uso                     |
|------------------------|-------------------------|
| `translate-en_es.argosmodel` | inglés → español  |
| `translate-es_en.argosmodel` | español → inglés  |

> Argos traduce entre idiomas sin par directo haciendo *pivote* por inglés,
> así que con los modelos `xx_en` y `en_xx` cubres muchas combinaciones.
